StitchCraft on your iPhone

No App Store purchase, paid developer account, custom domain, subscription, or AI is needed. Internet is needed for installation and updates; the installed app works offline after its download is verified.

1. Publish the prepared files for free

  1. Create or sign in to a free account at GitHub. Create a new repository named stitchcraft-iphone. Choose Public and add a README if offered. The app code will be public. Keep project backups and personal photos out of the repository.
  2. Unzip StitchCraft-iPhone.zip on your computer. Open the repository and choose Add file → Upload files (or the “uploading an existing file” link in an empty repository).
  3. Upload the contents of the extracted folder: index.html, mobile.js, sw.js, manifest.webmanifest, setup.html, and the three icon-*.png files. Include .nojekyll if your file picker shows it; the plain files also work without it. Do not upload the ZIP itself or put the files inside another folder. Commit the upload to the default branch, normally main.
  4. Open repository Settings → Pages. Under Build and deployment, choose Deploy from a branch, select main and / (root), then Save. If your branch has a different name, select that branch.
  5. Wait for deployment to finish, then use the HTTPS link shown by GitHub Pages. It usually looks like https://YOUR-USERNAME.github.io/stitchcraft-iphone/. Keep that address stable so the installed app keeps using the same local project storage.

2. Install on your iPhone

  1. Open that HTTPS address in Safari with an internet connection. Use an up-to-date iOS version.
  2. Tap Share → Add to Home Screen. Turn on Open as Web App if that option appears, then tap Add.
  3. Open the new StitchCraft icon from the Home Screen while still online. Wait for Offline ready. This must be checked inside the installed app, even if Safari already showed it.
  4. Optionally expand “Install, update & protect your projects” and request storage protection. The browser decides whether to grant it; backups are still needed.

3. Bring your desktop projects

  1. In desktop StitchCraft, open My patterns and export a JSON backup from its backup/recovery section.
  2. Transfer the JSON file to your iPhone’s Files app, for example through iCloud Drive or a file transfer you already use.
  3. Open StitchCraft using its Home Screen icon, choose My patterns → backup/recovery → Import JSON backup, select the file, review the import, then confirm. Importing into Safari does not guarantee the installed app will receive that data.
  4. Projects and photos stay on the device. Desktop and iPhone do not sync automatically. Export and import JSON backups to transfer changes; matching project IDs import as separate copies.

4. Test before traveling

  1. Confirm Offline ready, create or open a project, and check a round.
  2. Enable airplane mode and turn off Wi-Fi. Close and reopen StitchCraft from its Home Screen icon.
  3. Check that the project, marked round, part illustrations and photos still open. Make another change and reopen once more.
  4. Export a fresh JSON backup and save it to Files. Ensure any cloud-stored backup is downloaded locally if you need access without internet.

Updates and backups

Upload all files from a newer iPhone package to the same repository, replacing the old files. In the installed app, reconnect, tap “Check offline copy / updates,” then choose “Apply downloaded update” when ready. Updates wait for your choice and keep the local project store; export a backup first. Update files as a complete release so their versions match.

Clearing website data, removing the installed app, device loss, storage pressure or browser cleanup can remove local data. Keep JSON backups in Files or another location you control. A TXT instruction export cannot restore progress or photos. Screen-awake support depends on iOS and the browser.

If something does not work

  • GitHub shows 404: wait for deployment, check the Pages branch/root settings, and confirm index.html is at the repository root.
  • Offline setup fails: use the HTTPS site, not the HTML file in Files. Reconnect and retry. Check that all eight visible app files were uploaded.
  • Read-only: close other StitchCraft windows, then reopen or reload the installed app. If Web Locks are unavailable, update iOS. The app does not bypass its save-safety lock.
  • Projects seem missing: check whether you opened Safari or the Home Screen app, and whether the URL changed. Import your backup into the app you intend to use.
